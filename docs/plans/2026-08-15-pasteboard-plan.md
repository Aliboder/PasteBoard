# PasteBoard 实现计划

> 依据：`docs/superpowers/specs/2026-08-15-pasteboard-design.md`
> 技术栈：Rust + Tauri v2 + Svelte(TS) + rusqlite + windows crate
> 模式：单人 + AI 结对，晚间高效时段，每轮约 2~4 小时

---

## 项目概要

- **目标**：可用的本地剪贴板管理器 MVP（文本/图片/文件历史、搜索、固定、热键唤起、粘贴回原窗口、托盘常驻）
- **成功标准**：设计文档第 10.1 节"手动验收清单"7 项全部通过
- **工期预估**：6 个阶段，共约 7~9 轮（含返工缓冲 ~25%）
- **约束**：体积目标 ≤15MB；本地优先，无云

## 风险与应对

| 风险 | 影响 | 概率 | 应对 |
|------|------|------|------|
| Rust 学习曲线拖慢进度 | 高 | 高 | 每阶段小步验收；核心模块保持纯 Rust 可单测；AI 结对代写样板 |
| 图片位图(CF_DIB)解码复杂 | 高 | 中 | 预留 3.2 缓冲；参考 arboard 源码；失败则降级只存 PNG 重编码 |
| `SetForegroundWindow` 被系统限制 | 中 | 中 | 5.3 已有降级；备选 AttachThreadInput 方案记录在案 |
| WebView2 缺失（老系统） | 中 | 低 | 打包安装包内置 WebView2 引导安装选项 |
| 体积超标 | 中 | 低 | 禁用未用特性、strip 符号、体积纳入 6.3 验证 |
| 监听与粘贴的循环（自写误记录） | 中 | 中 | 300ms 守卫 + 单测覆盖；验收第 6 项专门验证 |

---

## 每轮节奏（建议）

1. 每轮开始：明确本轮目标（本表对应任务）
2. 完成后：跑该阶段提交点的验证，汇报证据（命令输出/截图/日志）
3. 用户确认后再进入下一阶段
4. 每阶段结束：`git commit` 一次，便于回退
