# PasteBoard

> 本地剪贴板管理器（Windows）——小巧、现代、本地优先，你的剪贴板时光机。

**PasteBoard** 会自动记录你复制过的**文本、图片和文件**。当你想找回半小时前复制过的一段话、一张截图或一个文件时，按一下热键，搜索、点击，即可粘贴回原处——再也不用担心复制内容被覆盖丢失。

**全部数据保存在本地**，不上传、不联网，完全离线使用。

---

## ✨ 核心功能

| 功能 | 说明 |
|---|---|
| 📋 剪贴板历史 | 自动记录文本 / 图片 / 文件，永不丢失（按你的设置保留上限，默认 500 条） |
| ⚡ 一键粘贴 | 点击条目或按 Enter，直接粘贴回你唤起前的窗口，光标位置精准恢复 |
| 🔍 实时搜索 | 顶栏输入关键字即时过滤，匹配内容高亮显示 |
| 📌 固定 | 把常用内容"钉"住，自动清理永远不会删掉它；固定内容集中在"固定"Tab 管理 |
| 🖼️ 查看大图 | 右键图片 → 查看大图，独立窗口按图片尺寸自适应显示，细节清晰 |
| 🎨 外观 | 深色 / 浅色 / 跟随系统三种主题；窗口大小自动记忆 |
| 🔒 隐私安全 | 数据 100% 本地存储，自动备份，密码框等内容请谨慎使用 |

## 🚀 快速上手

1. **安装**：下载安装包运行（也可用免安装的便携版）
2. **复制**：正常复制任何内容（Ctrl+C / 右键复制）
3. **唤起**：按全局热键 **`Ctrl+Shift+V`**（可在设置中自定义）弹出 PasteBoard
4. **粘贴**：点击条目（或方向键选择后按 Enter）——粘贴完成窗口自动隐藏

## 🖥️ 界面导览

- **类型 Tab**：全部 / 固定 / 文本 / 图片 / 文件——按类型快速筛选历史
- **全部视图**：上方图片/文件横条 + 下方文本列表
- **图片视图**：缩略图网格；**文件视图**：文件图标网格
- **设置**（顶栏 ⚙）：热键录制、历史上限、主题、开机自启、数据统计等

## ⌨️ 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl+Shift+V`（可改） | 唤起 / 隐藏主窗口（跟随鼠标位置） |
| `↑` / `↓` | 选择文本条目 |
| `Enter` / 点击 | 粘贴到原窗口并自动关闭 |
| `1` ~ `9` | 快速粘贴对应条目 |
| `Esc` | 关闭窗口 |
| `Delete` | 删除选中的文本条目 |

## 🔧 常见问题

**Q：复制的内容能保存多久？**
取决于设置中的"历史上限"（默认 500 条）。达到上限时自动清理**最旧的普通条目**；被**固定**的条目永远不会被自动清理。

**Q：文件条目删除了原文件会怎样？**
文件历史保存的是文件路径引用。原文件被删除或移动后，该条目会失效（点击无效）。图片类内容则完整保存在本地数据目录，不受原文件影响。

**Q：我的数据安全吗？**
安全。所有数据存储在本地 `%APPDATA%\com.aliboder.pasteboard\`，程序不联网、不收集任何信息。数据库会自动备份（保留最近 5 份），误删可到该目录的 `backup\` 找回。

**Q：复制过的密码会被记录吗？**
会。PasteBoard 忠实记录所有复制内容——**请不要用剪贴板管理器记录密码**。

**Q：重复复制相同内容会怎样？**
自动去重：相同内容只保留一条，并置顶到最前。

## 💾 数据位置

| 内容 | 路径 |
|---|---|
| 数据库 / 图片 / 缩略图 | `%APPDATA%\com.aliboder.pasteboard\` |
| 自动备份 | 同目录 `backup\`（保留最近 5 份） |
| 日志 | 同目录 `pasteboard.log` |

设置面板中可直接点击"打开数据目录"。

## 🛠️ 开发者信息

**技术栈**：Rust + Tauri v2 + Svelte 5(TS) + SQLite + Windows API

```bash
npm install          # 安装前端依赖
npm run tauri dev    # 开发模式（热更新）
npm run check        # 前端类型检查
cargo test           # Rust 单元测试
npm run tauri build  # 打包（NSIS + MSI + 便携版）
```

仓库 CI（GitHub Actions）自动执行格式检查、lint 与测试。
