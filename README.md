# PasteBoard

本地剪贴板管理器（Windows）——小巧、现代、本地优先。

## 功能

- 自动记录剪贴板历史：**文本 / 图片 / 文件**三种类型，事件驱动监听 + 轮询兜底
- **类型筛选 Tab**（全部 / 文本 / 图片 / 文件）：
  - 全部：上方图片/文件横向条 + 下方文本列表
  - 文本：文本列表撑满全高；图片：纵向网格（大缩略图）；文件：五列网格（图标/缩略图）
  - 与实时搜索叠加；搜索时**关键字高亮**
- **富文本保留**：浏览器/Word 等复制的格式内容粘贴时保留（CF_HTML），纯文本应用自动降级
- 悬停预览：图片大图预览（截图与文件形式图片均支持）、文本全文预览
- 文件类型图标：与资源管理器一致的**系统图标**（Shell API），图片文件直接显示**缩略图**
- 全局热键唤起（**按键录制自定义**），回车/点击**一键粘贴回原窗口**（焦点与光标位置精确恢复）
- **文本列表虚拟滚动**（上千条历史流畅）、大文本截断（悬停看全文）
- 星标固定（**视觉区分** + 固定项删除二次确认）、删除、清空（含固定需二次确认）
- **深色 / 浅色 / 跟随系统**三种主题
- 窗口**尺寸记忆**、可拖动、可置顶、点击外部自动隐藏、唤起跟随鼠标
- **开机自启**开关（设置与托盘联动）；托盘菜单：显示 / 清空历史 / 自启 / 退出
- 历史上限可配置（默认 500 条），SQLite 本地存储；**数据库自动备份**（backup/，保留 5 份）

## 使用

| 操作 | 说明 |
|---|---|
| 全局热键（默认 `Ctrl+Shift+V`） | 唤起 / 隐藏主窗口（唤起位置跟随鼠标） |
| `↑` / `↓` | 文本区选择（选中行自动滚入视野） |
| `Enter` / 点击 | 粘贴到唤起前的窗口并自动关闭 |
| 数字键 `1~9` | 快速粘贴文本区对应条目 |
| `Esc` | 关闭窗口 |
| `Delete` | 删除选中的文本条目 |
| 条目右侧 ★ / × | 固定 / 删除（悬停显示；固定项删除需二次确认） |
| 顶栏搜索框 / ⚙ | 搜索历史（关键字高亮）/ 设置 |
| 顶栏、底部栏 | 按住可拖动窗口；边缘可调整大小 |

## 开发

```bash
# 环境要求：Rust（MSVC 工具链）、Node.js 18+
npm install          # 安装前端依赖
npm run tauri dev    # 开发模式（热更新）
npm run check        # 前端类型检查（svelte-check）
cargo test           # Rust 单元测试
npm run tauri build  # 打包（NSIS 安装包 + MSI + 便携 exe）
```

## 数据位置

| 内容 | 路径 |
|---|---|
| 数据库 / 图片 / 缩略图 | `%APPDATA%\com.aliboder.pasteboard\` |
| 数据库自动备份 | `%APPDATA%\com.aliboder.pasteboard\backup\`（保留最近 5 份） |
| 日志 | `%APPDATA%\com.aliboder.pasteboard\pasteboard.log` |

## 技术栈

Rust + Tauri v2 + Svelte(TS) + SQLite(rusqlite) + Windows API（`AddClipboardFormatListener` 事件监听 + 轮询兜底、Shell 文件图标、焦点/选区精确恢复、CF_HTML 富文本）

## 说明与限制

- 文件类型历史保存的是**路径引用**，原文件被删除/移动后条目会失效（V2 计划支持文件副本）
- 相同内容重复复制会去重并顶到最前（纯文本条目可升级为富文本条目）
- 密码框等场景请谨慎使用历史功能
